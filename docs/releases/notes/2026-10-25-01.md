## Included

- Storefront Contact Us displays the support email configured in Platform Admin while keeping the existing Pin4MS contact path available. (#2772; PR #2782)
- Storefront sends best-effort order confirmation emails with tracking links and an order-page-aligned, branded receipt with itemization, VAT details, and best-effort catalog thumbnails (using monogram tiles when images are unavailable). The message keeps the order PIN and support link, omits invoice and provider payment references, and shows Manila times without the visible timezone suffix. (#532; PRs #2779, #2797, #2806)
- POS assigned-branch entry now checks effective permissions and location grants, enabling authorized branch users to continue through the sales journey. (#2767; PR #2777)
- Storefront discovery map image failures during teardown no longer interrupt the map's current source. (#2770; PR #2778)
- API shutdown drains active HTTP requests before closing Redis and tenant database connections. (#2769; PR #2775)
- Promotion quality evidence now appears in GitHub Actions summaries for matching-PR and no-PR runs. (#1165; PR #2780)
