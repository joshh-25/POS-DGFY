## Included

- POS staff can attach private delivery-completion photos and recipient signatures with assignment-scoped authorization and idempotent retries. (#1462, PR #1889)
- POS staff can attach optional private packing-evidence images after an order reaches `packed`, with authenticated reads and retry-safe storage. (#1460, PR #1890)
- Delivery Runs expose an optional transportation label through create, update, list, and detail flows. (#1463, PR #1888)
- Tenant staff can use editable capabilities and roles with effective-permission resolution and assignment-aware POS fulfillment enforcement. (#1459, PR #1881)
- DeliveryRun date-range schema repair and fresh-tenant fallback now include the scheduled end field and required index. (#1879, PR #1882)
- POS responsive-image fallback handling no longer races React reconciliation and avoids the recurring `removeChild` crash path. (#1880, PR #1883)
- Tenant provisioning keeps the delivery-evidence image index within MySQL’s identifier-length limit. (#1508, PR #1891)
- Backend quality-gate fixtures keep generated tenant database identifiers within MySQL’s identifier-length limit. (#1877, PR #1878)
- STAGING and CI API and migration-runner runtime image builds use a bounded HTTPS Alpine mirror fallback for transient package-index fetch failures, while failing closed if all official mirrors are unavailable. (#1895)

## Operational notes

The STAGING repair is included in candidate revisions `2026-09-13-01-r1` and `2026-09-13-01-r2`; the release remains pending production promotion.
