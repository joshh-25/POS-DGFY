## Included

- Partner sign-in no longer fails for OIDC clients whose ID or secret contains reserved characters: the token and pushed-authorization endpoints now decode Basic client credentials as RFC 6749 §2.3.1 requires, which unblocks the DGLaundry login handshake. (PR #2515; #2304)
- Catalog sync inserts geo items correctly instead of failing on the insert ID. (PR #2508; #528)
- The API logs a warning when the Sentry backend configuration is disabled, so a silent PROD misconfiguration is visible. (PR #2507; #2502)
- API transitive dependencies are updated to clear known vulnerabilities. (PR #2509; #2506)
