## Included

- Carries forward the seven selected application updates from candidate 2026-10-15-01: protected cashier refund/void, drawer, terminal identity, and X/Z workflows; Storefront QR category menus and shared scheduled-order checkout; POS recovery when a cashier's open shift is on another register or location; API visibility when Sentry is disabled; API dependency security updates; and the geo-item catalog sync fix. The prior PROD publish/deploy was cancelled, so these app changes remain unshipped. (PRs #2492, #2501, #2507, #2508, #2509; issues #2493, #2502, #2506, #528)
- Partner sign-in no longer fails for OIDC clients whose ID or secret contains reserved characters: the token and pushed-authorization endpoints now decode Basic client credentials as RFC 6749 §2.3.1 requires, which unblocks the DGLaundry login handshake. (PR #2515; #2304)
- Catalog sync inserts geo items correctly instead of failing on the insert ID. (PR #2508; #528)
- The API logs a warning when the Sentry backend configuration is disabled, so a silent PROD misconfiguration is visible. (PR #2507; #2502)
- API transitive dependencies are updated to clear known vulnerabilities. (PR #2509; #2506)
- POS records eligible paid cash refunds atomically with voids, keeps no-shift refunds recoverable, and prevents duplicate refund/telemetry effects on retries. (PR #2520; issues #2519, #2521)
- F&B Service is hidden from primary POS navigation while its existing route and access checks remain available. (PR #2520; issue #2522)
- POS Affiliate workspace presentation now covers responsive affiliate lists, pending invites, cashout, settings, invite and filtering flows, row actions, pagination, KPI cards, modals, and status-audit/reactivation UI while preserving existing service boundaries. (PR #2528; issues #1203, #1234)
