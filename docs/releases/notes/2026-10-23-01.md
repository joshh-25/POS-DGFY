## Included

- Carries forward all seven apps and the staged scope from candidate 2026-10-20-01; its frozen main promotion selection was PR #2712, which has not been merged or deployed to PROD. This also preserves the outstanding IMS, POS, and OPIS updates from #2227. (#2227; PR #2712)
- POS now uses consistent responsive headers, navigation, spacing, and layouts across Items, option groups, History, Z-reading, Reports, Shifts, Orders, Settings, and Pricelists. (#2713; PR #2714)
- Adds external partner discovery categories, PII-safe Proventus employer-pin extraction, and reversible Admin controls for partner types and pins. The main hotfix record remains separately preserved in `2026-10-23-01-hotfix-2715.md`. (#2715; PRs #2723, #2731)
- SynqCore event pins keep their property slugs and redirect to the property's lowest numeric room ID. (#2715; PRs #2730, #2731)
- Tenant Admin audit history accepts `apply_template` through the model and forward migration. (#2719; PR #2725)
- POS refund submission failures leave the dialog open for correction and retry without an unhandled rejection. (#2724; PR #2726)
- Business-registration draft uploads persist on MySQL with a nullable application link and forward migration. (#2718; PR #2727)
- Adds optional registered `epic/<n>-<slug>` and `feature/<n>-<slug>` integration branches, with CI parity, advisory reservation/readiness checks, an operator helper, and updated version, compliance, PR-routing, handoff, and policy guidance. This is a partial implementation of #2737; reservation-blocking and first-integration-merge flags remain off for separate follow-up actions. (#2737; PR #2744)
- Standardizes resume-compatible manual session snapshots across Planner, Worker, and Reviewer while preserving live-source checks and each role's action boundaries. (#2753; PR #2759)
