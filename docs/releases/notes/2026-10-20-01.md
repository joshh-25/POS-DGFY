## Included

- Platform Admin can retry eligible failed commerce refunds with a required reason and an audited retry chain. (#2549, PR #2627)
- Guests can submit feedback without an account, and submissions are stored for Platform Admin triage with optional identity details. (#561, #582; PRs #2622, #2624)
- Tenant database connections stay warm across POS polling, with added connection timing and pool diagnostics for operators. (#2560, PR #2623)
- The production operations guide now documents the required push-delivery variables and their provisioning order. (#2579, PR #2612)
- Platform Admin can control merchant storefront-visibility edits, and hidden stores reject new public activity while existing-order operations remain available. (#2633, PR #2637)
- POS now supports catalog-only business registration provisioning, branch-aware terminal selection and shift workflows, and clearer cash/Z-reading reconciliation. (PR #2636)
- OPIS now provides audited fulfillment-role and branch-grant management for owners and admins. (#1182, PR #2640)
- A platform-owned allowance controls whether stores can offer downpayment on new checkout and payment-session flows. (#2639, PR #2641)
- Storefront checkout refreshes missing or stale quotes after payment-rail changes and asks shoppers to review before resubmitting. (#2644, PR #2646)
- Customer cancellation follows the linked order and delivery lifecycle, with audit history and order-status history visible to operators. (#2666, PR #2672)
- POS supports direct F&B and Retail delivery with early courier assignment, atomic completion/failure handling, and customer courier timelines. (#2667, PR #2674)
- Orders awaiting courier pickup stay visible across POS, Storefront, and the business order center; direct delivery actions use the active terminal-paired POS operator. (#2676; PR #2679)
- POS and API direct-delivery rider assignment now uses one action, validates the rider, and appears only at supported fulfillment stages. (#2667, PR #2689)
- POS background refresh and same-shift resume preserve the active view and unsaved delivery fields. (#2688, PR #2692)
- Admin-managed partner redirect templates and external listing pins provide stable external listing redirects. (#2629, PR #2694)
- POS rejects item sale prices and unit costs outside the persisted decimal range. (#2686, PR #2695)
- Effective-permission dependencies keep API authorization, OPIS access, POS controls, and user-management permission editing aligned. (#2635, #1459; PR #2702)
- Customer delivery tracking now shows “Ready for pickup” across Storefront, API, and POS, while “Order placed” remains active until preparation begins. (#2703, PR #2705)
