## Included

- Platform Admin adds push diagnostics for environment readiness, device enrollment, dispatch and receipt states, and audited test sends to enrolled devices. (#2579, PR #2580)
- PayMongo unknown-session alerts now distinguish test-mode events while preserving alerts for live payments. (#1091, PR #2583)
- Platform Admin `/admin` redirects stay on the same host and avoid leaking the container port and HTTP scheme. (#2589, PR #2590)
- POS improves the Audit workspace with date filtering, readable event details, pagination, and responsive layouts; Affiliates tab transitions and Items navigation are also polished. (#2596, PR #2545)
- Reverse geocoding now uses a nearby street name in address labels, and Storefront delivery and service bookings require house or unit details. Saved addresses retain those details. (#2484, #2593, #2594; PRs #2597–#2599)
- Merchant location setup and editing now require and preserve street number, unit, floor, or building details. (#2595, PR #2601)
- Platform Admin can control push-diagnostics visibility separately for Storefront, POS, and Fiscal POS. (#2602, PR #2604)
- GeoCatalogSync now updates tenant-wide catalog snapshots without accumulating duplicate rows on each sweep. (#2605, PR #2606)
