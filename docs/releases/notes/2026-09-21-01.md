## Included

- POS checkout, catalog, terminal controls, and transaction history receive responsive desktop, tablet, and mobile refinements. (PR #1985)
- Tenant deletion now returns typed conflict responses, supports guarded registration-history cleanup, and records forced-delete audit actions. (PR #2007, issue #2005)
- POS tenant-wide Storefront Reviews preview no longer fails with HTTP 422. (PR #2003, issue #1998)
- Staging repair r1 replaces `verify-deployment.yml`'s single long-lived SSH poll session with
  short-lived per-poll SSH calls, so a transient mid-window connection drop can no longer
  false-fail verification of a healthy environment (issue #1783). No app runtime behavior or
  version changes are included.
