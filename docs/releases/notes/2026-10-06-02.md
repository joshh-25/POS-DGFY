## Included

- Retail checkout customers can search for a delivery address, and pinned-address reverse geocoding now uses dgfy-api instead of calling the third-party geocoder from the browser. (#506, #759; PR #2263)
- Platform Admin is delivered as the standalone dgfy-admin application, with isolated admin sessions and `/admin` routing across product hosts. (#350; PR #2246)
- POS parked-sale dialogs refresh approved cancellations automatically, browser printing works when no native printer is available, and shift-summary and Z-reading output support consistent 57mm/80mm widths. (#2260; PR #2268)
- Storefront customers can cancel unpaid PayMongo checkout sessions; confirmed cancellations are persisted and audited. (#2267; PR #2270)
- Delivery-address search is available in the F&B and Simple storefront checkouts, alongside Retail search. (#759; PR #2274)
- The staging candidate observation workflow now installs its required dependencies before running. (PR #2282)
- Storefront delivery-address fields preserve spaces while customers type. (PR #2283)
- Carry forward all seven apps selected for the previous staging candidate, which has not been promoted to production. (#2227; PR #2275)
