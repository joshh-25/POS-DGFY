## Included

- POS terminals retain the last successfully loaded F&B workflow after settings failures, block new checkout until a workflow resolves, and restore checkout after reconnect. This includes the already-deployed 2026-10-26-01 main hotfix and its follow-up. (#2824; back-port PR #2829, follow-up PR #2875)
- OPIS owners and admins can invite an existing DGFY account into an active custom staff role; deactivating that role cancels its pending invitations without revoking accepted memberships. (#2812; PR #2820)
- Storefront supports the DGFY browser OIDC interaction for DGLaundry sign-in, registration, password reset, and company selection. Joint hosted acceptance remains outstanding. (#2837; PR #2842)
- Storefront discovery shows DGFY-native listings by default and shows partner listings only after an explicit category selection; the Proventous display name is preserved. (#2833; PR #2843)
- Outbound email templates use DGFY branding while retaining configured sender identity and recipient-specific details; the follow-up clarifies template ownership and covers both branding and neutral-send contracts. (#2830; PR #2839; follow-up #2896 / PR #2914)
- DGLaundry operator tooling records environment-specific callback and partner origins, plus separate DGFY DEV and PROD connection configuration. (#2387, #2513, #2834; PRs #2835, #2836, #2838)
- Platform admins can search and filter the tenant directory, open bookmarkable tenant detail pages, and manage existing tenant controls in grouped sections while retaining the existing server-side safeguards. (#2696; PR #2841)
- POS and OPIS incorporate local BIR compliance and fiscal/receipt setup, role permissions, staff/shift, item, and approval updates. (#2140, #2635; PR #2859)
- Platform Admin can review DGLaundry registration requests, search/filter the queue, and approve, reject, or request corrections. Approval links the company, provider location, and owner membership; rejection and correction do not provision access. (#2826; PR #2857; ADR 0079)
- Storefront discovery clear/reset actions cancel search and clear query, filters, sort, page, selection, and map-cluster state while restoring the unsearched dataset. (#2833; PR #2865)
- Agent tooling lazy-loads role skills and checks always-loaded context usage. (#2854; PR #2856; repository tooling)
- POS settings and account flows preserve safe continuation, reopen the online cash-collection drawer, and refresh catalog state after SSE reconnect; OPIS staff-role editing is available through searchable business-admin settings; Storefront retains a verified account session after email verification. (#2918; PR #2922)
- POS MapLibre workers bootstrap the Chrome 80 compatibility shim and verify emitted worker assets. Chrome 80 device acceptance remains outstanding. (#2919; PR #2925)
- Tenant-connector LRU evictions emit fixed-caller, data-minimal attribution with an offline aggregation procedure; the instrumentation does not establish the underlying eviction root cause. (#2920; PR #2927)
- The 2026-10-28 Sentry triage record includes the later sanitized PROD-log correction to the #2920 analysis; it records findings without resolving the tracked issues. (#1074, #2919, #2920; PRs #2921 and #2924)
- DGLaundry production configuration now pins the staging-qualified `c87eac4` images and matching migration head while keeping DGFY integration mode disabled; this promotion records the repository config without deploying the external stack. (#2387; PR #2867; staging PR #2872)
