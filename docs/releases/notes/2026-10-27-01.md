## Included

- POS terminals retain the last successfully loaded workflow when store settings temporarily fail, then refresh settings after reconnect. This carries the already-deployed 2026-10-26-01 main hotfix back into the staging source line. (#2824; back-port PR #2829)
- OPIS owners and admins can invite an existing DGFY account into an active custom staff role; deactivating that role cancels its pending invitations without revoking accepted memberships. (#2812; PR #2820)
- Storefront supports the DGFY browser OIDC interaction for DGLaundry sign-in, registration, password reset, and company selection. Joint hosted acceptance remains outstanding. (#2837; PR #2842)
- Storefront discovery shows DGFY-native listings by default and shows partner listings only after an explicit category selection; the Proventous display name is preserved. (#2833; PR #2843)
- Outbound email templates use DGFY branding while retaining configured sender identity and recipient-specific details. (#2830; PR #2839)
- DGLaundry operator tooling records environment-specific callback and partner origins, plus separate DGFY DEV and PROD connection configuration. (#2387, #2513, #2834; PRs #2835, #2836, #2838)
