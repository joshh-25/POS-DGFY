# Documentation Images

This folder contains visual diagrams and images referenced in the project documentation.

## Diagram Files

### System Architecture
- **File**: `system-architecture-diagram.png` (or `.jpg`)
- **Description**: High-level system architecture diagram showing microservices, layers, and data flow
- **Referenced in**: `/docs/architecture/system-architecture.md`

### Data Model
- **File**: `data-model-diagram.png` (or `.jpg`)
- **Description**: Entity-relationship diagram showing database schema and table relationships
- **Referenced in**: `/docs/database/schema.md`

## Adding New Images

When adding new diagrams:

1. Save the image file in this folder with a descriptive name (lowercase, hyphens)
2. Update the relevant documentation file to reference it using relative paths: `./images/filename.png`
3. Use Markdown image syntax: `![Alt text](./images/filename.png)`

## Image Formats

- Preferred: PNG (for diagrams with text)
- Alternative: JPG (for photos), SVG (for scalable diagrams)
