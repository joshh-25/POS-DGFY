# Finding 2.5  DDL Execution via String Interpolation

## Status
Resolved

## Severity
Low

## Root Cause
Database creation used `` CREATE DATABASE IF NOT EXISTS `${dbName}` ``. Reliance on string interpolation for DDL is theoretically risky even when input is pre-sanitised.

## Fix Implemented
### 1. Module-level `DB_NAME_PATTERN` constant
```javascript
const DB_NAME_PATTERN = /^sku_tenant_[a-z0-9]+_[a-z0-9]+$/;
```
Single source of truth reused by all DDL paths.

### 2. Pattern validation  legacy flow (after `dbName` construction)
```javascript
if (!DB_NAME_PATTERN.test(dbName)) {
    throw new Error(`Security: Invalid database name generated: ${dbName}`);
}
```

### 3. Pattern validation  approval flow (on `providedDbName`, previously unvalidated)
```javascript
dbName = providedDbName;
if (!DB_NAME_PATTERN.test(dbName)) {
    throw new Error(`Security: Invalid database name in approval flow: ${dbName}`);
}
```

### 4. `quoteIdentifier()` for CREATE DATABASE
```javascript
const safeCreateIdentifier = sequelize.getQueryInterface().quoteIdentifier(dbName);
await sequelize.query(`CREATE DATABASE IF NOT EXISTS ${safeCreateIdentifier}`);
```

### 5. Upgraded guard + `quoteIdentifier()` for DROP DATABASE
```javascript
// Before: !dbName.startsWith('sku_tenant_')
if (!dbName || !DB_NAME_PATTERN.test(dbName)) {
    throw new Error('Invalid database name for deletion (must match sku_tenant_<name>_<uuid>)');
}
const safeDropIdentifier = sequelize.getQueryInterface().quoteIdentifier(dbName);
await sequelize.query(`DROP DATABASE IF EXISTS ${safeDropIdentifier}`);
```

### 6. Inline pre-call guard in catch block updated
```javascript
// Before: dbName.startsWith('sku_tenant_')
if (dbName && DB_NAME_PATTERN.test(dbName)) { ... }
```

## Finding Description
Database creation used `` CREATE DATABASE IF NOT EXISTS `${dbName}` ``. Reliance on string interpolation for DDL is theoretically risky even when input is pre-sanitised.

## Severity
 Low

## Root Cause
In `backend/src/services/tenantProvisioningService.js`:

```javascript
const safeName = name.toLowerCase().replace(/[^a-z0-9]/g, '');
dbName = `sku_tenant_${safeName}_${uuid.split('-')[0]}`;
// ...
await sequelize.query(`CREATE DATABASE IF NOT EXISTS \`${dbName}\``);
```

- The regex `/[^a-z0-9]/g` was functionally safe but the code relied on its implicit correctness.
- The approval flow (`isApproval === true`) received `dbName` from the caller with **no validation whatsoever** before use in DDL.
- `deleteTenantDatabase` used a weak `startsWith('sku_tenant_')` prefix check rather than a full pattern assertion.
- Both DDL statements used hand-rolled backtick interpolation instead of ORM-mediated escaping.

## Fix Applied

### 1. Module-level `DB_NAME_PATTERN` constant
```javascript

```
Single source of truth reused by all DDL paths.
