#  RESOLVED - 6.5 Missing BOM Handling

## Status
Resolved

## Severity
Low

## Root Cause
The CSV parser is not configured to handle the UTF-8 Byte Order Mark (BOM), causing header mapping issues.

## Fix Implemented
### Analysis
A Byte Order Mark (BOM) for UTF-8 is the byte sequence `0xEF 0xBB 0xBF`. When read natively as a UTF-8 string, it is interpreted as the invisible character `\uFEFF`.
If a CSV from Excel (saved as "CSV UTF-8") is uploaded, the parser reads the first header (e.g., `"sku_code"`) as `"\uFEFFsku_code"`. Thus, `row.sku_code` evaluates to `undefined`, causing validation failures and silent data dropping.

### Implementation Verified
Code analysis confirms that the proposed fix is **already active in the codebase**:
1. `csvImportService.js` (L29): `bom: true // Fix 6.5: Handle UTF-8 Byte Order Mark`
2. `supplierCSVService.js` (L23): `bom: true // Fix 6.5: Handle UTF-8 Byte Order Mark`

The `csv-parse` library's `bom: true` natively detects and strips the sequence on the first chunk of data.

## Finding Description
The CSV parser is not configured to handle the UTF-8 Byte Order Mark (BOM), causing header mapping issues.

## Severity
 Low

## Proposed Plan

### 1. Root Cause Analysis
In `backend/src/services/csvImportService.js`:
- The `parse` function options (Lines 17-22) do **not** include `bom: true`.
- **Code**:
    ```javascript
    const records = parse(csvContent, {
        columns: true,
        skip_empty_lines: true,
        trim: true,
        // bom: true <--- MISSING
    });
    ```
- **Scenario**:
    - User edits CSV in Excel and saves as "CSV UTF-8 (Comma delimited)".
    - Excel prepends `0xFEFF` (BOM) to the file.
    - Parser reads the first header `sku_code` as `\uFEFFsku_code`.
    - `transformRow` checks `if (row.sku_code)`. It returns undefined because the key is `\uFEFFsku_code`.
    - Import fails or skips data silently.

### 2. Proposed Changes
Enable BOM detection in the parser.

#### A. Modify `parseCSV` in `csvImportService.js`
Add `bom: true` to the options.

```javascript
/* csvImportService.js */
const records = parse(csvContent, {
    columns: true,
    skip_empty_lines: true,
    trim: true,
    bom: true // <--- Fix
});
```
*Also apply to `supplierCSVService.js` if it shares the same pattern.*

### 3. Verification Plan

#### Automated Test
1.  Create a CSV string with a BOM: `\uFEFFsku_code,name\nSKU1,Test`.
2.  Call `parseCSV`.
3.  **Expect**: `records[0].sku_code` exists.
4.  **Current Behavior**: `records[0]['\uFEFFsku_code']` exists, `records[0].sku_code` is undefined.

#### Manual Verification
1.  Open Excel.

3.  Upload to system.
4.  **Expect**: Success.
