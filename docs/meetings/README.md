# Meeting notes

Raw capture from stakeholder meetings, produced by the `notes` role
(`.agents/skills/notes/SKILL.md`, #331/#645). One file per meeting:
`<YYYY-MM-DD>-<topic-slug>.md`. Flat — deliberately no subfolder taxonomy. `docs/Radney
Suggestions/` tried a 9-folder structure for this kind of capture; 11 of its 14 files are still
empty READMEs. A flat list of dated files stays simple enough to actually get used.

## Authority

Every file here is `authority_level: historical` — raw, unedited stakeholder words, never a rule
source. A decision worth keeping doesn't stay here; it gets routed into an ADR amendment, a
governed doc, or a GitHub issue during that meeting's compile step, and the note file just remains
as the record of where the decision came from.

## Format

Append-only, timestamped, numbered notes (`N001`, `N002`, …) so a later note can supersede an
earlier one by ordering without editing it. See `.agents/skills/notes/SKILL.md` for the full note
file template and the prime/capture/compile procedure that produces these files.
