# Implementation Plan - 8.3 Temp File Leak on Server Restart

## User Feedback
> Create a cleanup system that will intelligently remove temporary files on the disk

## Finding Description
`tempFileService` relies on `setTimeout` for cleanup, so files remain if the server restarts before the timeout.

## Severity
🟢 Low

## Proposed Plan

### 1. Root Cause Analysis
In `backend/src/controllers/csvImportController.js`:
- `previewImport` handles file uploads.
- **Bug 1 (Crash)**: It attempts to access `req.file.buffer`. Since `uploadConfig.js` uses `diskStorage`, `.buffer` is `undefined`. This triggers a 500 Error on every file upload.
- **Bug 2 (Leak)**: Multer saves the file to `uploads/temp`. The controller reads it (or tries to) but **never deletes it**.
- **Reliance on Cleanup**: The system relies entirely on `cleanupService.js` (cron) to delete files every 15 minutes.
- **Risk**:
    - Functional: File upload import is broken.
    - Resource: An attacker can flood the disk with uploads faster than the cron job deletes them (DoS).

### 2. Proposed Changes
Fix the buffer access and implement Immediate Cleanup.

#### A. Modify `csvImportController.js`
1.  Import `fs` (fs/promises).
2.  In `previewImport`:
    - Check if `req.file.path` exists.
    - Read file content using `fs.readFile`.
    - **Finally**: Delete the file using `fs.unlink`.

```javascript
/* csvImportController.js */
import fs from 'fs/promises';

export const previewImport = async (req, res) => {
    let filePath = null;
    try {
        let csvContent;
        if (req.file) {
            filePath = req.file.path;
            csvContent = await fs.readFile(filePath, 'utf-8');
        } else {
            // ... body ...
        }

        // ... process ...

    } catch (error) {
        // ...
    } finally {
        // cleanup
        if (filePath) {
            try {
                await fs.unlink(filePath);
            } catch (e) {
                // ignore
            }
        }
    }
};
```

### 3. Verification Plan

#### Automated Test
1.  POST `/import/preview` with a valid CSV file.
2.  **Expect**: 200 OK (Success).
3.  Check `uploads/temp` immediately.
4.  **Expect**: File is GONE.

- **Impact**: Medium (Fixes file import, prevents disk fill).
- **Regression**: None.
