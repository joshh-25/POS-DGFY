# [RESOLVED] 1.1 Dependency Vulnerabilities Block Production

Severity: Critical
Audit area: Supply chain, application security, release readiness
Resolved date: 2026-06-02

## Finding

The repository previously had unresolved dependency vulnerabilities across root, backend, and frontend package scopes. These included production dependency advisories in root/backend and a critical dev-tooling advisory in the frontend test runner.

## Remediation Summary

Dependency manifests and lockfiles were updated across all package scopes:

- Root:
  - `axios` updated to `^1.16.1`
  - `basic-ftp` updated to `^5.3.1`
  - `lodash` override added at `4.18.1` for dev-tooling audit hygiene
- Backend:
  - Direct runtime dependencies updated: `axios@^1.16.1`, `express@^4.22.2`, `mammoth@^1.12.0`, `multer@^2.1.1`, `nodemailer@^8.0.10`, `sequelize@^6.37.8`, `uuid@^11.1.1`
  - Scoped overrides added for vulnerable transitive packages whose upstream ranges still lag patched versions: `@xmldom/xmldom`, `brace-expansion`, `dottie`, `lodash`, `path-to-regexp`, `uuid`, `underscore`, and dev-tooling packages used by Jest/ESLint/Sequelize CLI
- Frontend:
  - Test/build tooling updated to Vite 8 / Vitest 4 patched line: `vite@^8.0.16`, `vitest@^4.1.8`, `@vitejs/plugin-react@^6.0.2`, `jsdom@^29.1.1`

Release enforcement was also added:

- Root scripts:
  - `npm run audit:dependencies:prod`
  - `npm run audit:dependencies`
- Local release gate:
  - `scripts/gate-release-local.js` now blocks on both production-only and full dependency audits.
- CI:
  - `.github/workflows/ci.yml` now runs an explicit `dependency-audit` job.
  - Namecheap packaging and main build jobs now depend on the audit job.

## Verification Evidence

The following audit commands returned `0` vulnerabilities on 2026-06-02:

- `npm audit --json`
- `npm audit --omit=dev --json`
- `npm --prefix backend audit --json`
- `npm --prefix backend audit --omit=dev --json`
- `npm --prefix frontend audit --json`
- `npm --prefix frontend audit --omit=dev --json`

## Residual Exceptions

None. No vulnerable production or dev dependency advisories remain in the current locked dependency trees.

## Release Notes

This finding is security-sensitive, production-config-sensitive, payment-sensitive, and release-readiness-sensitive. The fix intentionally treats test/build tooling vulnerabilities as release blockers because they affect evidence generation and CI integrity.

`--no-audit` deterministic install flags remain permitted in deployment/package steps only when paired with explicit dependency audit gates.
