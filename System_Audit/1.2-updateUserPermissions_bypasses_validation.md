## Proposed Plan

### 1. Root Cause Analysis
The defined route `PUT /:user_id/permissions` in `userController.js` directly deconstructs `req.body` without passing it through any Joi validation middleware. While the code attempts some manual checks (e.g., `if (!Array.isArray(permissions))`), it relies on ad-hoc implementation which is prone to errors and inconsistency compared to the standardized Joi validators used elsewhere.

### 2. Proposed Changes
We will standardize the validation by adding a specific Joi schema and middleware.

#### A. Add Schema to `backend/src/validators/userValidator.js`
We will define `updateUserPermissionsSchema` and its corresponding middleware `validateUpdateUserPermissions`.

```javascript
// Schema for updating user permissions (Master Admin only)
export const updateUserPermissionsSchema = Joi.object({
  permissions: Joi.array().items(Joi.string()).required().messages({
    'array.base': 'Permissions must be an array',
    'any.required': 'Permissions array is required',
    'string.base': 'Permission items must be strings'
  }),
  is_master_admin: Joi.boolean().strict().optional().messages({
    'boolean.base': 'is_master_admin must be a boolean'
  })
});

/**
 * Middleware to validate user permission update request (Master Admin only)
 */
export const validateUpdateUserPermissions = (req, res, next) => {
  const { error, value } = updateUserPermissionsSchema.validate(req.body, { abortEarly: false });

  if (error) {
    const errors = error.details.map(detail => ({
      field: detail.path[0],
      message: detail.message
    }));

    return res.status(422).json({
      success: false,
      data: null,
      message: 'Validation failed',
      errors,
      timestamp: new Date().toISOString()
    });
  }
  
  // Replace body with validated values to strip unknown fields
  req.body = value;
  next();
};
```

#### B. Apply Middleware in `backend/src/routes/users.js`
We will inject this middleware into the route definition to ensure it runs before the controller logic.

```javascript
// BEFORE
router.put('/:user_id/permissions', authenticate, authorize('admin'), userController.updateUserPermissions);

// AFTER
import { validateUpdateUserPermissions } from '../validators/userValidator.js';
// ...
router.put('/:user_id/permissions', authenticate, authorize('admin'), validateUpdateUserPermissions, userController.updateUserPermissions);
```
