# Audit 3.4 - Simplified date logic causes billing drift

## Status
Resolved

## Severity
Unspecified

## Root Cause
A fixed `+30 days` extension model causes billing drift and can desynchronize subscription period boundaries from PayPal's authoritative schedule.

## Fix Implemented
1. Authoritative provider billing timestamps are preferred.
- `handlePaymentCompleted` resolves period end from `resource.next_billing_date` first, then `resource.billing_info.next_billing_time`.
- Evidence: `backend/src/controllers/paymentController.js` (around lines 175-180).

2. Calendar-aware fallback is used when authoritative timestamp is unavailable.
- Fallback uses one calendar-month extension with anchor-day snap-back (`extendOneCalendarMonth`).
- Evidence:
  - `backend/src/controllers/paymentController.js` (around lines 27-35 and 182-188)
  - `backend/src/models/Landlord/Tenant.js` (`billing_cycle_anchor`, around lines 63-70)

3. Period end is monotonic.
- `nextBillingDate` is guarded by `maxDate(nextBillingDate, current_period_end)` so old events cannot move period backward.
- Evidence: `backend/src/controllers/paymentController.js` (around lines 190-193).

4. Anchor backfill safety is in place for existing premium rows.
- Conservative backfill only updates premium tenants with null anchor and non-null `current_period_end`.
- Evidence:
  - `backend/migrations/20260303000005-backfill-missing-billing-anchor.cjs`
  - `backend/tests/billingAnchorBackfill.migration.test.js`

## Test Evidence
1. Webhook regression coverage
- `backend/tests/paypalWebhookHandlers.test.js`
- Relevant scenarios:
  - uses authoritative `next_billing_date`
  - does not move `current_period_end` backward when authoritative date is older
  - fallback month-based behavior when authoritative date is missing

2. Route + DB integration coverage
- `backend/tests/subscriptionIntegration.test.js`
- Confirms upgrade path stores PayPal `next_billing_time` and keeps `current_period_end` monotonic.

## Residual Risk
A fixed `+30 days` extension model causes billing drift and can desynchronize subscription period boundaries from PayPal's authoritative schedule.
