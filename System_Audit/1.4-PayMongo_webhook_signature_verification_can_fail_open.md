# [OPEN] 1.4 PayMongo Webhook Signature Verification Can Fail Open

Severity: Critical
Audit area: Payments, webhook integrity

## Finding

PayMongo webhook verification can return success when the webhook secret is missing.

## Evidence

- `backend/src/services/paymongoService.js` returns `true` when `PAYMONGO_WEBHOOK_SECRET` is not configured.
- `scripts/deploy.sh` requires the PayMongo webhook secret by default, but the application code itself still contains fail-open behavior if the secret is absent.

## Why This Matters

Payment webhook handlers must authenticate event origin and integrity. A fail-open signature check can allow forged payment lifecycle events if the application is deployed with payment routes reachable and the secret missing.

## Required Remediation

1. Fail closed for missing PayMongo webhook secret in production and payment-enabled environments.
2. Make the handler reject unsigned or unverifiable webhook requests before business logic runs.
3. Keep local/test bypasses explicit and environment-scoped.
4. Add tests for missing secret, invalid signature, replayed event, and valid event.

## Acceptance Gates

- Production missing secret returns a rejection, not success.
- Invalid signature cannot reach payment state mutation.
- Replay protection is tested.
- Deployment secret checks and runtime behavior agree.
