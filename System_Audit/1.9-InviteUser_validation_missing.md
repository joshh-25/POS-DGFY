# [FIXED] 1.9 `inviteUser` controller lacks Joi validation

## Status: ✅ FIXED
**Date**: 2026-02-16
**Resolution**: Implemented `Joi` validation schema and middleware in `userValidator.js`, applied it to the `/invite` route, and updated the controller to use `req.validatedData`.

## User Feedback
> Make it more consistent

## Finding Description
The `inviteUser` controller does manual `if (!email || !role)` validation instead of using a Joi validator middleware.

## Severity
🟢 Low

## Proposed Plan

### 1. Root Cause Analysis
The `inviteUser` function in `userController.js` (lines 183-206) performs basic checks (`if (!email || !role)`), but:
1.  **No Schema Validation**: It does not validate if `email` is a valid email format.
2.  **No Role Validation**: It accepts *any* string as a role (e.g., "super-admin", "hacker"), although `userService.createUserInvitation` might default it to 'staff' if invalid, relying on deep service logic for validation is bad practice. Validator should stop it at the gate.
3.  `userValidator.js` has no schema for invitations.

### 2. Proposed Changes
We will enforce strict input validation using Joi.

#### A. Add Schema to `backend/src/validators/userValidator.js`
Define `inviteUserSchema` and `validateInviteUser` middleware.

```javascript
// Schema for inviting a user (admin only)
export const inviteUserSchema = Joi.object({
  email: Joi.string().email().required().messages({
    'string.email': 'Please provide a valid email address',
    'any.required': 'Email is required'
  }),
  role: Joi.string().valid('admin', 'manager', 'staff').required().messages({
    'any.only': 'Role must be one of: admin, manager, staff',
    'any.required': 'Role is required'
  })
});

/**
 * Middleware to validate user invitation request (admin only)
 */
export const validateInviteUser = (req, res, next) => {
  const { error, value } = inviteUserSchema.validate(req.body, { abortEarly: false });

  if (error) {
    // ... standard error handling ...
    return res.status(422).json({ ... });
  }

  req.validatedData = value; // Store validated data
  next();
};
```

#### B. Update Route in `backend/src/routes/users.js`
Apply the new middleware.

```javascript
// BEFORE
router.post('/invite', authenticate, authorize('admin'), userController.inviteUser);

// AFTER
import { validateInviteUser } from '../validators/userValidator.js';
// ...
router.post('/invite', authenticate, authorize('admin'), validateInviteUser, userController.inviteUser);
```

#### C. Clean up `userController.js`
- Remove the manual `if (!email || !role)` check since the validator handles it.
- Use `req.validatedData` instead of `req.body`.
