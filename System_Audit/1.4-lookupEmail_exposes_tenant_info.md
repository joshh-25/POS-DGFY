# Implementation Plan - 1.4 `lookupEmail` exposes tenant info to unauthenticated users

## User Feedback
> Research first on so that we can figure out how we can secure this

## Finding Description
The `POST /auth/lookup` endpoint is unauthenticated and returns `company_token`, `company_name`, and `tenant_id` for any valid email. With multiple tenants, it returns an array of all tenant details.

## Severity
🟡 Medium

## Proposed Plan

### 1. Root Cause Analysis
The `POST /auth/lookup` endpoint is designed to help users find which tenant they belong to by entering their email.
- **Vulnerability**: It returns specific tenant details (`name`, `company_token`, `tenant_id`) directly to the public client.
- **Risk**: An attacker can enumerate emails to find valid users and their associated companies. This is an Information Disclosure vulnerability.

### 6. Implementation Status
✅ **Implemented**: 2026-02-16

#### Changes:
- Added `lookupLimiter` to `backend/src/middleware/rateLimiter.js` (5 requests / 15 mins).
- Applied `lookupLimiter` to `POST /api/v1/auth/lookup` in `backend/src/routes/auth.js`.
- Improved error message for transparency and security.
