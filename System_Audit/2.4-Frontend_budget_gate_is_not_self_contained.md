## Why This Matters

Performance gates must be deterministic and actionable. If a gate depends on build artifacts, the release pipeline should either build them as part of the gate or require and verify a prior build step explicitly.

## Required Remediation

1. Decide whether the budget gate owns the frontend build or validates a required prebuilt artifact.
2. Encode the build/prebuilt-artifact decision in the release gate.
3. Add a clear artifact path and freshness check.
4. Preserve budget output in release artifacts.
5. Keep route budgets documented when thresholds change.

## Acceptance Gates

- Frontend budget gate is reproducible from a clean checkout.
- Missing or stale built assets produce a clear precondition failure before release verdict calculation.
- Core Web Vitals or equivalent bundle/performance budgets are documented.
- `npm run gate:release:local` remains green after the self-contained budget contract is updated.
