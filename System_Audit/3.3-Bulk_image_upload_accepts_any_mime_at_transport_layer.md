# [OPEN] 3.3 Bulk Image Upload Accepts Any MIME at Transport Layer

Severity: High
Audit area: File upload security, resource abuse

## Finding

The bulk catalog image upload transport filter accepts any MIME type before deeper validation occurs.

## Evidence

- `backend/src/config/uploadConfig.js` configures a bulk catalog image upload path where the multer file filter accepts files at the transport layer.
- The same upload configuration allows many files and megabytes per file before later business validation can reject content.

## Why This Matters

File upload controls should reject unsafe content as early as possible. Transport-level acceptance of arbitrary MIME types increases exposure to resource abuse, parser attacks, malware storage, and mismatched extension/content handling.

## Required Remediation

1. Enforce MIME and extension allowlists at the multer/file-filter layer.
2. Validate file magic bytes before persistence or downstream processing.
3. Cap file counts and sizes by tenant plan and workflow need.
4. Ensure rejected files are cleaned from temp storage.
5. Add tests for invalid MIME, spoofed extension, oversized file, and mixed valid/invalid batch.

## Acceptance Gates

- Bulk image upload rejects non-image content before business logic.
- Spoofed extension with invalid magic bytes is rejected.
- Temp files are cleaned after rejection.
- Upload DoS limits are covered by tests.
