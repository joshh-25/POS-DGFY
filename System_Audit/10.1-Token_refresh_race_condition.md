# ? RESOLVED - Implementation Plan - 10.1 Race Condition in Token Refresh Logic

## User Feedback
> Create a plan that could make simultaneous refresh tokes succeed

## Finding Description
The Axios interceptor lacks request queuing. Multiple concurrent 401s trigger multiple parallel refresh requests, causing race conditions with Refresh Token Rotation.

## Severity
🟠 High

## Proposed Plan

### 1. Root Cause Analysis
In `frontend/src/services/api.js`:
- The response interceptor (Line 39) detects 401 errors.
- It immediately attempts to refresh the token: `axios.post(...)`.
- **Vulnerability**: There is no "isRefreshing" lock.
- **Scenario**:
    - Page loads -> Calls API A, API B, API C.
    - Token is expired. All 3 return 401.
    - Interceptor runs 3 times in parallel.
    - 3 Refresh requests sent to backend.
    - Backend rotates token on first request.
    - Subsequent 2 requests fail because the Refresh Token is now recycled/invalid.
    - App forces logout.

### 2. Proposed Changes
Implement the "Mutex" pattern for Token Refresh.

#### A. Modify `api.js`
1.  Add module-level variables: `isRefreshing = false` and `failedQueue = []`.
2.  Add `processQueue(error, token = null)` helper.
3.  In interceptor:
    - If `isRefreshing` is true, return a Promise that pushes `resolve/reject` to `failedQueue`.
    - If `isRefreshing` is false:
        - Set `isRefreshing = true`.
        - Call refresh endpoint.
        - On success: process queue with new token, retry original.
        - On error: process queue with error, logout.
        - Finally: `isRefreshing = false`.

```javascript
/* api.js */
let isRefreshing = false;
let failedQueue = [];

const processQueue = (error, token = null) => {
  failedQueue.forEach(prom => {
    if (error) {
      prom.reject(error);
    } else {
      prom.resolve(token);
    }
  });
  failedQueue = [];
};

// Inside Interceptor
if (error.response?.status === 401 && !originalRequest._retry) {

            originalRequest.headers['Authorization'] = 'Bearer ' + token;
            return api(originalRequest);
        }).catch(err => {
            return Promise.reject(err);
        });
    }

    originalRequest._retry = true;
    isRefreshing = true;
```
