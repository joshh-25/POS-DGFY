#  RESOLVED - 9.1 Authentication Rate Limiting Disabled

## Status
Resolved

## Severity
High

## Root Cause
The `authLimiter` middleware was originally disabled or using a basic in-memory store, leaving login endpoints vulnerable to brute-force in production. The system lacked distributed state sharing and proxy awareness, meaning attackers could bypass limits by spreading traffic across multiple nodes or origins.

## Fix Implemented
### 1. Distributed State (Redis)
Implemented `rate-limit-redis` via a custom `DynamicStore` wrapper in `backend/src/middleware/rateLimiter.js`.
- **Syncing**: Rate limit counters are shared across all Node instances (e.g., PM2 cluster).
- **Resilience**: Implemented a "seamless fallback" that preserves memory-based rate limiting if the Redis connection is lost.

### 2. Network & Proxy Hardening
- **Proxy Trust**: Configured `app.set('trust proxy', 1)` in `backend/src/server.js` to correctly identify client IPs behind reverse proxies (Nginx/Cloudflare).
- **IP Extraction**: Implemented `firstForwardedIp` logic to ensure `X-Forwarded-For` is prioritized correctly, preventing internal proxy IPs from being throttled.

### 3. Selective Application
The `authLimiter` is applied directly to sensitive routes in `backend/src/routes/auth.js`:
- `/login`, `/register`: Protected by strictly keyed `ip_email` limits.
- `/lookup`: Protected by `lookupLimiter` to prevent email enumeration.

## Test Evidence
### True E2E Network Validation
Implemented a specialized test in `backend/tests/auth.ratelimit.e2e.test.js`:
- **Real Network Port**: Unlike standard `supertest(app)`, this test spawns a child process listening on a real HTTP port.
- **Proxy Spoofing**: Simulates genuine attack traffic through mocked proxy headers.
- **Result**: Successfully triggered 429 errors only for the spoofed IP, while allowing traffic from other "simulated" origins.

### Summary of Protection
- **Window**: 15 minutes.
- **Auth Limit**: 5 attempts per IP/Email pair (Production).
- **Enumeration Limit**: 5 attempts per IP (Lookup).
