<objective>
Deliver SC2's genuinely-new code: an interactive, on-demand migration-runner command that discovers active tenants from the registry, lets the operator pick which businesses this release-evidence run targets (D-02/D-03), and produces two distinct reviewable reports — tenant-drift by reusing verify.js's existing contract-comparison engine (checkContractSchema), and migration-verification by reusing verify.js's existing migration-metadata/idempotency engine (the now-exported checkMigrationMetadata helper that reads the dgfy_migration_meta ledger).

Purpose: Replace the static DGFY_BUSINESS_DB_NAMES env target list with a live, human-in-the-loop selection that excludes test-only businesses, so migration/drift evidence only covers real migration targets.
Output: A new `release-evidence` runner subcommand, an exported drift engine, the @inquirer/prompts dependency, and JSON+markdown drift/verification reports written under an evidence directory the Wave 2 orchestrator passes in.
</objective>
