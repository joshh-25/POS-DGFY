<threat_model>
OWASP ASVS Level 1 framing: apply mode is the highest-risk Phase 03 boundary because it mutates DGFY target data.

| Threat | STRIDE | Severity | Component | Disposition | Mitigation / Block Condition |
|--------|--------|----------|-----------|-------------|------------------------------|
| Target-list tampering | Tampering | high | `runDataApply` | mitigate | Use 03-01 manifest validator and include sanitized target identifiers in audit; block if apply can run without manifest. |
| SQL injection / unsafe DB names | Tampering | high | `apply.js` | mitigate | DB names come only from validated manifest/env; values use replacements or query-interface methods. |
| Secret leakage in reports | Information Disclosure | high | apply report | mitigate | Redact sensitive fields; block if tests show secrets in report or command args. |
| Privilege escalation through inferred memberships | Elevation of Privilege | high | assignment/business membership writes | mitigate | Writes require accepted membership evidence; conflict and skip otherwise per ADR 0028. |
| Duplicate writes on retry | Tampering | high | `legacy_id_map`, checkpoints | mitigate | Lookup maps before insert, use target unique constraints, mark checkpoints after writes; block if retry tests fail. |
| Repudiation / audit gaps | Repudiation | high | command/finding/checkpoint metadata | mitigate | Command rows, map rows, checkpoint rows, findings, and reports are required for every apply run. |
</threat_model>
