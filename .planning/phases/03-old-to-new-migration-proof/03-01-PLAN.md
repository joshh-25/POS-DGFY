<threat_model>
OWASP ASVS Level 1 framing: validate all operator input before use, avoid secret disclosure, enforce explicit access evidence, preserve auditability, and block high-risk findings before proceeding to later waves.

| Threat | STRIDE | Severity | Component | Disposition | Mitigation / Block Condition |
|--------|--------|----------|-----------|-------------|------------------------------|
| Target-list tampering migrates unintended tenant | Tampering | high | `targetManifest.js` | mitigate | Reject blank, duplicate, malformed, or implicit manifests before connection; block execution if tests do not prove no auto-discovery per D-01. |
| SQL injection / unsafe DB names | Tampering | high | `env.js`, `db.js`, `dataState.js` | mitigate | Regex-validate target DB names, reject `dgfy_*` as legacy source tenant DB, use Sequelize replacements for values; block on any string-interpolated untrusted value. |
| Secret leakage in reports/metadata | Information Disclosure | high | `.env.example`, metadata findings | mitigate | Store/report IDs, counts, and reason codes only; never write DB passwords, password hashes, terminal hashes, OTPs, or `company_token`; block on tests/grep finding those secrets in fixture reports. |
| Privilege escalation through inferred memberships | Elevation of Privilege | high | manifest expected IDs | mitigate | This plan records expected owner/account IDs only as assertions; membership creation is planned in 03-04 and must require accepted membership evidence from ADR 0028. |
| Duplicate writes on retry | Tampering | high | `legacy_id_map`, `data_checkpoints` | mitigate | Unique scoped metadata constraints and lookup-before-insert helpers; block if duplicate map/checkpoint tests fail. |
| Repudiation / audit gaps | Repudiation | medium | `command_executions`, `data_quality_findings` | mitigate | Every command gets durable execution row and every skipped/conflict record gets a durable finding row. |
</threat_model>
