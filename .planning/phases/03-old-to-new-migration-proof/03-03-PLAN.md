<threat_model>
OWASP ASVS Level 1 framing: dry-run crosses untrusted source data and operator manifest input into report/audit output while promising no DGFY mutation.

| Threat | STRIDE | Severity | Component | Disposition | Mitigation / Block Condition |
|--------|--------|----------|-----------|-------------|------------------------------|
| Target-list tampering | Tampering | high | `runDataDryRun`, `legacySource` | mitigate | Load only manifest-listed tenants and reject invalid manifests before DB connection; block on tests proving no tenant enumeration. |
| SQL injection / unsafe DB names | Tampering | high | `legacySource` | mitigate | Use validated DB names and Sequelize replacements/placeholders for values; block on interpolated untrusted value review. |
| Secret leakage in reports | Information Disclosure | high | dry-run reports | mitigate | Redact passwords, hashes, OTPs, terminal secrets, and `company_token`; block if fixture report contains these fields. |
| Privilege escalation through inferred memberships | Elevation of Privilege | high | dry-run mappers | mitigate | Missing accepted membership is conflict/skipped write evidence, not a planned assignment. |
| Duplicate writes on retry | Tampering | medium | dry-run target probes | mitigate | Dry-run must classify existing target rows as updates/no-ops using ID-map and unique target constraints, preparing apply retry behavior. |
| Repudiation / audit gaps | Repudiation | medium | command/finding metadata | mitigate | Persist command execution and every data-quality finding with execution ID. |
</threat_model>
