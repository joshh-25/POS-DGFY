| dgfy-api -> device-bridge (host HTTP) | outbound print request with API key |
| caller -> compliance gate | payment-handoff context influences fiscal decision |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-09-03-01 | Tampering | stock ledger single-writer | high | mitigate | sale effect goes through inventory's recordMovementWithStockSync only; availments never writes inventory_movements (ADR-0029). |
| T-09-03-02 | Info Disclosure | DEVICE_BRIDGE_API_KEY | medium | mitigate | API key read from env, sent only as an auth header, never logged or embedded in code. |
| T-09-03-03 | Denial of Service | hung device-bridge blocks finalize | medium | mitigate | AbortController short timeout + fail-open resolution so a slow/dead printer cannot hang or fail a recorded sale. |
| T-09-03-04 | Elevation of Privilege | fiscal gate bypass via payment context | medium | mitigate | only a whitelisted set of context fields is forwarded; policyEngine decision logic is unchanged (not edited). |
