</objective>

<threat_model>
OWASP ASVS Level 1 framing: database schema is a durable authorization and tenant-routing control surface. High-risk schema integrity issues block this plan.

## Trust Boundaries
| Boundary | Description |
|---|---|
| Runner -> `dgfy_core` | Migration can create/alter landlord identity and tenancy tables. |
| `dgfy_core` -> `dgfy_business_*` | Registry rows point future access and verification to tenant databases. |
| Public discovery -> core projection | Projection data may be exposed to public Storefront discovery later. |

## STRIDE Threat Register
| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-02-02-01 | Spoofing | `accounts` identity fields | high | mitigate/block | Add unique indexes for account email/phone identifiers as appropriate and status fields required for later auth checks. |
| T-02-02-02 | Tampering | `business_database_registry` | high | mitigate/block | Unique suffix/database constraints, status fields, verification timestamps, and audit log linkage per D-08/D-09. |
| T-02-02-03 | Information Disclosure | `storefront_discovery_index` | medium | mitigate | Projection table contains public routing/search metadata only; no `company_token`, credentials, internal product allocation, or tenant secrets. |
| T-02-02-04 | Elevation of Privilege | `business_memberships` | high | mitigate/block | Membership role/status/uniqueness constraints must support owner/manager/member semantics without relying on tenant-local role alone. |
| T-02-02-05 | Tampering | legacy schemas | high | mitigate/block | Target DB guard and Plan 04 fingerprints prove no legacy `sku_*` schema mutation. |
</threat_model>
