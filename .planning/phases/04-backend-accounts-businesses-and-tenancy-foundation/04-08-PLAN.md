## Rationale

`04-VERIFICATION.md` identified `TerminalIdentity.js` as orphaned because tenant-scoped model files were not instantiated in live-app composition. Terminal identity APIs are not part of the Phase 04 public endpoint scope, but the model must still be concretely definable through the same tenant connection registry as Location, StaffAccount, StaffInvitation, and AccountStaffAssignment. This plan wires that model-factory path and adds verification so the finding is closed without inventing a public terminal endpoint.
