<task type="auto">
  <name>Task 3: Create Business Use Cases — businessUseCases.js</name>
  <files>backend/src/modules/businesses/usecases/businessUseCases.js</files>
  <action>
Create businessUseCases.js with builders:

**buildCreateBusinessUseCase({repository})**
- Input: {legal_name, display_name, business_handle, creatorAccountId}
- Validates all fields required; business_handle unique
- Calls repository.create() (which auto-assigns creator as owner)
- Returns ApplicationResult.success({business, membership})
- Returns ApplicationResult.failure if validation fails or duplicate handle

**buildListUserBusinessesUseCase({repository})**
- Input: {accountId}
- Calls repository.findAccountBusinesses(accountId)
- Returns ApplicationResult.success({businesses: [...]})

**buildGetBusinessUseCase({repository})**
- Input: {businessId}
- Returns ApplicationResult.success({business})
- Returns NOT_FOUND on not found

**buildUpdateBusinessUseCase({repository})**
- Input: {businessId, updates: {legal_name?, display_name?, status?}}
- Validates fields
- Calls repository.update()
- Returns ApplicationResult.success({business})

**buildOnboardStaffViaInvitationUseCase({repository, sendEmail})**
- Input: {businessId, email, name}
- Creates invitation record (with token + expiry) in landlord DB (invitations table or temporary storage)
- Generates acceptance token
- Sends email with acceptance link (via sendEmail)
- Validates email not duplicate in this business
- Returns ApplicationResult.success({invitation: {token, email, business_id, ...}})
- Returns appropriate error if validation fails
- **Important:** Staff does NOT receive DgfyAccount or StaffAccount yet; account is created during acceptance (Wave 3.5 or later)

**buildOnboardStaffDirectUseCase({repository})**
- Input: {businessId, email, name, initialPassword?}
- Creates StaffAccount record immediately (in tenant DB — tenant session aware; Wave 4 concern)
- Validates email not duplicate in this business
- If initialPassword provided: owner set password; if not: generate temporary password
- Returns ApplicationResult.success({staffAccount: {email, name, ...}})
- **Important:** StaffAccount is tenant-scoped; does not have password. Password stored in DgfyAccount (landlord) after staff logs in and registers/accepts.

**buildAcceptInvitationUseCase({repository})**
- Input: {invitationToken}
- Validates token exists and not expired
- Creates assignment record
- Marks invitation accepted
- Returns ApplicationResult.success({assignment: {...}})

**buildListBusinessMembersUseCase({repository})**
- Input: {businessId}
- Returns ApplicationResult.success({members: [...]})

All use cases return ApplicationResult; use DomainError for domain failures.
