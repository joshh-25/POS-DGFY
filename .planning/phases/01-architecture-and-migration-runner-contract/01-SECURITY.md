## Unregistered Flags

None. No `## Threat Flags` section exists in `01-01-SUMMARY.md`, `01-02-SUMMARY.md`, `01-03-SUMMARY.md`, or `01-04-SUMMARY.md`. Independent scan of the implementation for new attack surface not covered by the register (dynamic `require()` paths, raw SQL string interpolation, CLI argv parsing, raw `mysql2` connections) found nothing outside what T-01-01 through T-01-12/T-01-SC already account for. `src/metadata/storage.js`'s `executed()` method builds a SQL string via `` `SELECT name FROM ${this.tableName} ...` `` — `tableName` is not attacker-controlled at any current call site (all three callers construct `MetaSequelizeStorage` with the default `SCHEMA_MIGRATIONS_TABLE` constant, never a runtime-supplied value), so this is not logged as a new flag, but is noted here for visibility should a future phase add a caller-supplied `tableName`.
