<objective>
Establish the `apps/dgfy-migration-runner` standalone package (per D-01) with a pure, DB-connection-free environment validation module (RUN-03), lazy DB connection factories, and the destructive-operation / target-database-name safety gates that every command handler in later plans must call before touching a database.

Purpose: RUN-03 requires the runner to "validate required environment variables, target database names, runtime mode, and destructive-operation flags before connecting to any database." This plan builds that validation layer as pure, independently-testable modules, structurally guaranteeing (not just by convention) that no DB connection can happen before validation passes.
Output: `apps/dgfy-migration-runner/` package scaffold, `src/config/env.js`, `src/config/db.js`, `src/safety/destructiveGate.js`, `src/safety/targetGuard.js`, `src/utils/errors.js`, `src/metadata/checksum.js`, and their unit tests.
</objective>
