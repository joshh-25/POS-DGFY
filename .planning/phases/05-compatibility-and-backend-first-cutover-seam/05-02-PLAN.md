| Boundary | Description |
|----------|-------------|
| domain layer ↔ compatibility/continuity code | The canonical dgfy-api entities/usecases must never import compat code; the guardrail + eslint enforce this boundary. |
| code in repo ↔ CI acceptance gate | A code-level seam must not be accepted (merged) without a complete active manifest entry; CI is the acceptance authority. |
