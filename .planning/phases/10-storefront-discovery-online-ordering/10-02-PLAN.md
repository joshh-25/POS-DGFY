<objective>
Add an Inventory-owned stock-reservation capability so a storefront order can place a temporary hold on stock (D-07), auto-release it on expiry (D-09), and convert it into a sale on finalize — all while keeping `modules/inventory` the sole writer of stock effects (ADR 0029).

Purpose: This is the tenant-side write that D-10 fails-fast on and the mechanism that closes the oversell race. It is a NEW capability the storefront requests through a port, exactly like the existing `recordSaleEffect`, never a direct stock write.
Output: A tenant `inventory_reservations` table + model, an Inventory-owned reservation repository/usecases (reserve / commit / release / expireDue / availableToSell), and unit tests. No storefront code here — this plan only exposes the ports.
</objective>
